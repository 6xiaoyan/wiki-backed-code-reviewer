# §2.2 变量声明 — 避免短变量名

## 关联规则
- §2.2 变量声明 — 避免短变量名

## 代码特征

以下代码模式会触发该违规：

- 函数/方法的形参名称只有一个字符，例如 `n`、`s`、`p`、`b`、`v`。
- 该单字符参数不属于允许的单字符场景：
  - 循环计数器：`i` / `j` / `k`
  - 3 行内临时变量
  - 坐标：`x` / `y` / `z`
  - 模板参数：`T` / `U`
- 典型的违规写法：
  ```cpp
  // 头文件
  void setNotes(const std::string& n);

  // 源文件
  void PasswordDialog::setNotes(const std::string& n)
  {
      m_edtNotes->setText(QString::fromStdString(n));
  }
  ```
- 常见特征：方法名含明确语义，但参数名没有表达语义，例如：
  - `setNotes(const std::string& n)` → `n` 应该表达 `notes`
  - `setName(const std::string& n)` → `n` 应该表达 `name`
  - `setFileName(const std::string& s)` → `s` 应该表达 `fileName`
  - `setVisible(bool v)` → `v` 应该表达 `visible`
- 该违规可能同时存在于头文件声明和源文件定义中，也可能只存在于其中一侧。

## 修复步骤

请按以下步骤修复：

1. **定位单字符形参**  
   在相关头文件（`.h`）和源文件（`.cpp`）中搜索形似以下模式的位置：
   - `const std::string& n`
   - `const std::string& s`
   - `bool v`
   - `int n`
   结合函数名和函数体判断该参数是否为单字符形参。

2. **判断是否属于允许的单字符场景**  
   如果该参数用于：
   - `for (int i = 0; ...)`
   - 临时变量且生命周期不超过 3 行
   - 数学/图形处理中的 `x` / `y` / `z`
   - 模板参数 `T` / `U`
   则不需要修复。  
   否则进入下一步。

3. **根据语义确定描述性名称**  
   根据函数名和参数用途确定新名称：
   - `setNotes(const std::string& n)` → `notes`
   - `setName(const std::string& n)` → `name`
   - `setFileName(const std::string& s)` → `fileName`
   - `setVisible(bool v)` → `visible`
   - 如果无法从函数名直接确定，阅读函数体后使用表达该参数含义的英文单词。

4. **修改源文件中的函数定义**  
   将参数名重命名为描述性名称，并同步替换函数体内所有对该参数的引用。  
   示例：
   ```cpp
   // 修复前
   void PasswordDialog::setNotes(const std::string& n)
   {
       m_edtNotes->setText(QString::fromStdString(n));
   }

   // 修复后
   void PasswordDialog::setNotes(const std::string& notes)
   {
       m_edtNotes->setText(QString::fromStdString(notes));
   }
   ```

5. **同步修改头文件中的函数声明**  
   将声明中的单字符形参改为一致的新名称，避免声明与定义不一致。  
   示例：
   ```cpp
   // 修复前
   void setNotes(const std::string& n);

   // 修复后
   void setNotes(const std::string& notes);
   ```

6. **不要改动调用方代码**  
   形参名不参与函数签名，调用方的实参写法不受影响，不需要修改。

7. **检查命名风格**  
   新参数名应遵循项目已有的命名风格，通常是 camelCase 或 snake_case，保证可读性和一致性。

8. **编译验证**  
   编译项目，检查是否有遗漏的旧参数名引用。如果出现编译器错误，说明还有未替换的位置，需继续更新。
