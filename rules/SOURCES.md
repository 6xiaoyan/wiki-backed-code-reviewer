# 规则文本来源说明

本目录只包含**完成审查所必需**、且由仓库所有者维护的规则文本：

| 文件 | 用途 |
|---|---|
| `C++代码规范.md` | 全仓模式下 `get_rules_text("cpp")` 的规范原文 |
| `QT代码开发规范.md` | `get_rules_text("qt")` |
| `SQLite加密.md` | `get_rules_text("sqlite")` |
| `git规范.md` | Git 提交规范参考（PR 模式的 Git 检查已内嵌确定性规则） |

## 未包含的第三方资料

以下第三方指南的**全文**没有复制到本仓库：

- Google C++ Style Guide
- Qt Coding Style
- Tencent C/C++ 安全指南

`code_checker/rules-wiki/` 中的 Wiki 页面是面向审查场景整理的规则条款、
检查方法与示例，部分页面在正文中标注了参考来源。这些页面保留原有来源说明，
本仓库不为它们附加新的许可证。

## 使用限制

- 这些规则文本随审查程序一起被视为**可信配置**；PR 分支中的同名文件不会生效。
- 修改规则文本属于审查配置变更，需要维护者在默认分支上评审后合入；
  PR 审查模式不会自动评测或发布 Wiki 变更。
